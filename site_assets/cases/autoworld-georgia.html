Для продавцов и импортёров автомобилей

Telegram-бот с приложением для продажи авто

В вашем канале появится ссылка «Подобрать авто». Она откроет бота вашей компании, а из него — каталог с ценами и заявками прямо в Telegram. Скачивать приложение из App Store или Google Play не нужно.

Что меняется для вас и покупателя

01 / Вы

Публикуете автомобили

Размещаете объявления в своём канале. Настроенный импорт переносит фотографии, цены и параметры в каталог приложения. Повторно заполнять карточки не нужно, если данные в посте подходят для импорта.

02 / Покупатель

Находит подходящую машину

Открывает бота, выбирает авто по марке, цене и году, смотрит подробности и оставляет заявку с нужными параметрами. Не приходится искать старые посты.

03 / Менеджер

Получает готовый запрос

Бот и приложение сохраняют заявки и контакты, которые покупатель предоставил. Менеджер видит их в рабочей панели и ведёт сделку.

Одна система продаж для вашей компании

Бот, приложение и рабочая панель работают с одними и теми же автомобилями, клиентами и заявками.

Покупатель видит

Ваш логотип, каталог с фото и ценами, фильтры, запрос расчёта и заявку на автомобиль.

Менеджер видит

Кто обратился, по какой машине, с каким бюджетом и что уже сделано по запросу. Уведомления и статусы можно настроить под вашу работу.

Владелец видит

Количество заявок, популярные автомобили и источники обращений при настроенном учёте. Можно связать статистику с рекламой.

Можно подключить мой сайт или CRM?

Подключим существующие источники автомобилей и заявок, если доступны необходимые API или выгрузки. Не нужно менять рабочую систему без необходимости. Возможность интеграции проверяем перед оценкой.

Что можно добавить для вашего бизнеса?

Для импорта — расчёт доставки, таможни и цены под ключ, этапы заказа; для дилеров — тест-драйвы, наличие и резервирование; для автоподбора — заявка по бюджету и отчёт о проверке; дополнительно — AI-консультант, уведомления, рекламная аналитика.

Задача: связать объявления об автомобилях с удобным поиском и обработкой заявок.

Решение: каталог, импорт объявлений, сценарии расчёта и заявок, рабочие роли и Telegram-уведомления.

Для вашей компании: адаптируем проверенные компоненты под ваши источники данных, оформление, способы расчёта и рабочие процессы.

Техническая реализация проекта

Telegram Bot API и Mini App, JavaScript, Node.js, Yandex Serverless Containers, YDB, Yandex Object Storage, GitHub Actions. В репозитории предусмотрена регулярная синхронизация каталога. Состав функций и интеграций для нового проекта согласуется отдельно.
