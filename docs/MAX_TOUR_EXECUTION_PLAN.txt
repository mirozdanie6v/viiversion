Demo Admin rules:
- all mutations are scoped to current HttpOnly demo session;
- verified tours are changed through demo_tour_overrides, not by editing verified base;
- user-created demo tours stay in demo_user_created_tours;
- schedules/availability are explicitly demo_availability;
- promotions are explicitly demo_promo;
- browser demo can work without Telegram credentials;
- real /api/v1/admin remains protected by Telegram auth + RBAC.

SOURCE-GROUNDING DECISIONS

1. Tour detail page wins over a catalog teaser when the official site conflicts with itself.
2. Dalat Premium verified baseline is $52 adult / $38 child from the detail page; catalog currently shows $52 / $43.
3. Dalat VIP verified baseline is $45 adult / $32 child from the detail page; catalog currently shows $45 / $35.
4. The Nha Trang day-city private-price overlap at exactly seven people is documented and not silently resolved.
5. A missing five-person private price for the two-day Dalat program is not inferred.
6. No real live availability is claimed until MAX TOUR provides a source/integration.
7. No real payment provider or commission is claimed until selected by MAX TOUR.
